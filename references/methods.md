# 方法学说明

本文说明流水线里每个分析**实际做的是什么**、以及**为什么这么做**。
每个结论的适用范围写在产物 JSON 的 `limitations` 字段里 ——
那些不是免责声明，是结论本身的一部分。

---

## 0. 数据获取

Visium 的数据是两半：

| 文件 | 内容 |
|---|---|
| `filtered_feature_bc_matrix.h5` | 表达矩阵（spot × 基因的 UMI 计数） |
| `spatial.tar.gz` | `tissue_positions*.csv`（坐标）、`scalefactors_json.json`、H&E 图像 |

**只读矩阵会得到一个普通的单细胞数据集，而分析者以为自己有空间数据。**

### 坐标的列序

`obsm['spatial']` 存 `(x, y) = (pxl_col_in_fullres, pxl_row_in_fullres)`。
这是 squidpy/scanpy 的约定。

**写反了不会报错** —— 散点图仍然画出"看起来像组织形状"的点阵。
流水线里所有坐标都通过 `common.spatial_xy()` 取，不直接访问
`adata.obsm["spatial"]`。

### Space Ranger v1 vs v2 的坐标文件名

- v1：`tissue_positions_list.csv`（**无表头**）
- v2：`tissue_positions.csv`（**有表头**）

把 v2 当 v1 读会**静默吃掉一个 spot**（表头被当成数据行），
或者列名全错。`common.read_tissue_positions()` 两种都处理。

## 1. spot 质控

### 与单细胞 QC 的本质差别

**spot 是 1-10 个细胞的混合物，不是单个细胞。**

后果：
- `pct_counts_mt` 的分布比单细胞**窄得多**（多个细胞的线粒体信号被平均）
- 单个 spot 的 UMI 少（Visium 每 spot 约 1k-10k，单细胞是 5k-50k）
- **过滤掉一个 spot 会在地图上留一个洞** —— 洞会改变空间邻居图，
  进而影响下游所有空间分析

### 阈值是组织特异的

| 组织 | `max_pct_mt` |
|---|---|
| PBMC | 5-10 |
| 淋巴结 | 20 |
| 心肌 | 30-50 |
| 肝 | 30+ |

用 PBMC 的阈值套到心肌上会滤掉大部分 spot。

### 组织连通性检查

过滤后检查组织是否被割裂成互不相邻的几块（用六边形邻居图的连通分量）。
单细胞里滤掉细胞没有几何后果；空间数据里会留洞，洞够大时组织被切开，
而空间邻域/niche/通讯**只在块内有效**。

### 线粒体基因前缀

人是 `MT-`，小鼠是 `mt-`。**用错前缀会让 `pct_counts_mt` 全 0，
过滤形同虚设，而日志里看不出任何异常。** `01_qc.py` 在匹配到 0 个
线粒体基因时直接抛异常。

## 2. 标准化与降维

### HVG 在 Visium 上的含义不同

Visium 的 spot 是多个细胞的混合物，所以 **HVG 会偏向"细胞组成差异"
而不是"细胞状态差异"**。

这对空间域划分是**想要的**（域本来就反映组成差异），但不能把 HVG
解读成"同一类细胞内的调控差异"。

### seurat_v3 口味的顺序要求

`seurat_v3` 内部对**原始计数**做负二项拟合，所以必须在
`normalize_total` + `log1p` **之前**跑；`seurat` / `cell_ranger` 相反。

**顺序反了不报错，只是给出错的 HVG** —— 而 HVG 错了下游全部跟着错。

### PC 的空间投影诊断

把 PC1-3 的分数画在组织上。**有空间结构才说明主成分抓到了组织学差异，
而不是技术噪声。** 这是空间数据特有的诊断，单细胞流程里没有。

## 3. 空间域

### 空间域 ≠ 表达簇

这是本步骤存在的全部理由。

普通的 Leiden 聚类只看表达相似度，**不知道 spot 在哪**，所以：
- 同一个空间连续区域可能被切成几块
- 两个不相邻的区域可能被合成一个簇

空间域要求"域内空间连续"，做法是把每个 spot 的表达与**空间邻居**
平均后再聚类。

### 量化"空间性"

| 指标 | 含义 |
|---|---|
| `neighbor_same_frac` | 相邻 spot 同域比例。**必须与随机基线比较** |
| `random_baseline_same_frac` | Σ 各域占比²（随机划分下的期望同域率） |
| `spatial_enrichment` | 两者之差 |
| `fragmented_domains` | 被切成多块的域数（**解读要小心**） |

**`fragmented_domains` 高不等于聚类失败。** 淋巴结的滤泡、肿瘤的癌巢
本身就是散布的多个斑块 —— 同一个域出现在多个不相邻位置是生物学事实。
只有对"应当连续"的组织（脑的层状结构、上皮分层）才能当缺陷看。

### 空间邻居图的构造

用 **kNN + 距离阈值**，不是纯 kNN。Visium 六边形网格里，
6 个直接邻居的距离是 `d`，次近邻是 `√3·d ≈ 1.73d`。
阈值取 `1.6 × 最近邻距离中位数` —— 正好把直接邻居包进来、
把次近邻挡在外面。

纯 kNN 会把组织边缘的 spot 和距离很远的 spot 连起来。

### 平滑强度的选择

平滑不是无代价的：α 过高会把真实的微小结构（如小的生发中心）抹平。
所以扫描多个 α，报告"空间连贯性 vs 域数"曲线，让选择有依据。

### 域标签的 z-score

**第一版直接比"该域里各类型 marker 的平均表达"，结果 13 个域里
12 个都被标成 `Plasma_cell`。**

原因：浆细胞的 marker（MZB1/JCHAIN/IGHG1/IGKC）在淋巴结里表达量
本来就极高，绝对表达一比就压倒所有其他类型。

正确的问法是"**哪个域对某个类型相对最富集**"：按类型跨域做 z-score，
消掉"某些类型 marker 天生高表达"的偏差，再取最高。

## 4. 空间高变基因（SVG）

### SVG ≠ HVG

| | 问的问题 |
|---|---|
| HVG | 这个基因在**样本之间**变异大吗？（不看位置） |
| SVG | 这个基因在**空间上**有结构吗？（邻居比随机更相似吗） |

一个基因可以既是 HVG 又不是 SVG，也可以反过来。

### Moran's I

```
I = (n / S0) · (x' W x) / (x' x)
```

`x` 是中心化后的表达，`W` 是空间权重矩阵，`S0 = Σ w_ij`。

无空间自相关时 `E[I] ≈ -1/(n-1)`（不是 0）。实测期望值 −0.00025。

**I 的数值依赖 `W` 的定义。** 换邻居数或标准化方式会得到不同值，
所以权重矩阵的参数一并落盘。

### 为什么自己实现而不调 squidpy

squidpy 的 `spatial_autocorr` 在版本间改过参数名与返回结构。
自己实现约 20 行（向量化，一次算全部基因），比跟着上游 API 漂移更稳，
而且能明确控制置换方式。

### 置换检验

置换的是**表达值在 spot 上的分配**（打乱空间位置），保留表达分布。
这检验的是"这个基因的空间排布是否比随机更结构化"。

**+1 校正**：`p = (n_ge + 1) / (n_perms + 1)`，避免 p=0
（有限次置换下不可能有比 `1/(n_perms+1)` 更小的 p）。

**必须做多重检验校正。** 4000 个基因里一定有一堆 p<0.05，那只是基因多。

### 用全基因集而不是 HVG

HVG 是按"样本间变异"选的，**会漏掉空间结构强但整体变异不大的基因** ——
而那正是 SVG 要找的。所以从 `adata.raw` 取全基因集，按方差粗筛后
做置换检验（控制耗时）。

## 5. spot 组成

### 两种模式

| 模式 | 是什么 | 何时用 |
|---|---|---|
| `builtin` | **marker 打分法**（相对富集） | 没有 scRNA-seq 参考 |
| `h5ad` | **NNLS 解卷积**（参考谱覆盖全部共同基因） | 有参考 |
| `none` | 不做，写明原因 | 不打算做 |

### 为什么 builtin 不是解卷积

**第一版用 NNLS 解 `y ≈ S^T w`，结果完全错：**
12 种类型的组成全部约等于 0.085 ≈ 1/12，重建误差中位 0.64，
3836/4025 个 spot 超过误差阈值。

原因是参考谱被构造成"只在 marker 基因位置非零，其余为 0" ——
模型在说"**非 marker 基因应该不表达**"，而实际上它们表达得很正常。
残差被这些基因主导，NNLS 只能给一个无意义的均匀解。

更根本的问题：方程 `y[markers] = Σ_k w_k · s_k[markers]` 里的
`s_k`（每种类型在 marker 上的参考表达谱）是未知的。
从目标数据本身估出来是循环论证。

**没有外部参考时，marker-only NNLS 不是适定问题。**

所以 `builtin` 模式改成 marker 打分法，产物里写明
`is_deconvolution: false`。

### 打分法做什么

对每种类型算一个相对富集分数：
该类型 marker 的平均表达 − 该 spot 全部基因的平均表达（校正测序深度），
再除以该类型 marker 在全部 spot 上的标准差（把不同类型放到可比尺度），
最后按 spot 归一化成相对权重。

**这不给出细胞比例。** 它给出"这个 spot 里哪类细胞的标志基因更活跃"。

### 重建误差是必报的诊断量

真解卷积模式下，误差大的 spot 说明"这套参考解释不了它" ——
可能是有未列入的类型，或者是技术坏点。**不报误差的话，
一个完全解释不了的 spot 也会得到一个看起来正常的组成。**

## 6. 空间邻域 / niche

### 邻域富集

统计量：类型 i 与类型 j 之间在邻居图上的**边数**。
零分布：保持各类型的 spot 数，随机重排标签。

**置换检验在这里是关键。** 两个类型相邻，可能只是因为它们各自
都占了很大面积（大类型的邻居当然多）。置换保持数量、打乱位置，
零分布正好扣掉这个效应 —— 所以 z 高才是"真的偏好相邻"。

### 共现

随距离增大，类型 a 周围出现类型 b 的比例怎么衰减。
能区分"紧密共定位"与"大范围共存"。

只对占比 >=2% 的类型做（稀有类型的分母太小，曲线全是噪声）。

### argmax 硬分配的代价

细胞类型层面的分析用解卷积权重的 argmax。
**这是硬分配，丢失了 spot 内的混合信息** ——
一个 60% T 细胞 + 40% B 细胞的 spot 会被当成纯 T 细胞。

## 7. 空间通讯

### 核心增量

**只有空间上接近的细胞才可能通讯。**

普通单细胞流程算配体-受体，隐含假设"样本里所有细胞都可能互相作用" ——
在 5000 个细胞里，A 类细胞和 B 类细胞永远"共现"，所以永远算出信号。
空间数据能加一个真实的约束：只统计距离在阈值内的 spot 对。

### 必须用全基因集

配体/受体大多是低表达基因，**几乎不进 HVG**。

实测：Part 2 在 2000 个 HVG 上 38 对里只有 3 对可用；
换到全基因集变成 27 对。空间这边全基因集上 **62/63 对可用**。

**假阴性看起来和"真的没有"一模一样**，所以宁可报错也不要悄悄退回 HVG。

### 这不是"通讯与否"的判定

算的是"空间约束下的配体×受体共表达强度"，是**描述性量**。

真正的细胞通讯推断需要 CellPhoneDB / CellChat 那样的统计框架
（含置换检验与受体复合物建模）。

**共表达 ≠ 通讯。** 两个基因在同一个 spot 里高，可能是同一个细胞
表达了两者（自分泌），也可能是两个细胞紧邻 ——
而 Visium 的 spot 含 1-10 个细胞。
