# CONTEXT.md — AI辅助生信分析工作台 · 领域术语表

> 本文件是术语的唯一权威。写代码、写文档、写台账时一律使用这里的词，不要另造同义词。
> 与实现无关，只定义"我们说的词是什么意思"。

## 三条分析线

| 术语 | 定义 | 不是 |
|---|---|---|
| **线1 / bulk 线** | GEO bulk 线：GEO 芯片或 bulk RNA-seq → 预处理/注释 → 多数据集整合去批次 → QC → 分组 → PCA → DEG + WGCNA → 富集 + PPI/hub → 交集关键基因 → ML 建模 → 独立 GEO 外部验证 | 不是需要单细胞数据的线 |
| **线2 / scrna 线** | 单细胞转录组 + 虚拟敲除线。虚拟敲除是本线**末端模块**，不是独立一条线 | 不是"单细胞通用线"，本线必含虚拟敲除收尾 |
| **线3 / spatial 线** | 单细胞空间转录组 + 虚拟敲除线。虚拟敲除同样是本线**末端模块** | 不是"空间转录组通用线"，本线必含虚拟敲除收尾 |

## 核心约束

| 术语 | 定义 |
|---|---|
| **互不交叉** | 三条线之间：不互相取参考、不合并数据集、不跨线验证。这是架构硬约束，不是工作习惯 |
| **项目 (project)** | 数据面的隔离单位：一个项目 = 一套独立的三条线数据目录（`projects/<项目>/<线>/{raw_data,processed,results,figures}`）。项目之间物理隔离，互不引用。脚本 `bin/` 与环境声明 `envs/` 全局一份，所有项目共用 |
| **默认项目** | `default`。历史三线数据（迁移前直接位于 `bio_data` 顶层）的迁入处，也是无 `project` 参数时的落点 |
| **线内混用** | R/Python 可以在**同一条线内部**按工具分工混用（如线2：Scanpy 做 QC、Seurat 做 marker、scTenifoldKnk 做敲除）。混用指工具层，不是分析线交叉 |
| **DEG** | Differentially Expressed Gene，组间差异表达基因（bulk 线 limma/DESeq2，线2 pseudobulk）。关注**表达变化** |
| **DR genes** | Differentially Regulated Gene，虚拟敲除后的差异调控基因。关注**调控变化**。**DR 基因不是 DEG**，两个概念不允许混写 |
| **主语言锁定** | 每条线固定一个主语言与版本（写进该线 envs/ 配置），不在分析中途切换，避免状态漂移 |

## 计算面

| 术语 | 定义 |
|---|---|
| **本地交互层** | PC。只跑浏览器 / IDE 远程视图。零算力参与计算 |
| **底座面** | 算力节点的基础用户空间。只做编排、文件传输、通道管理，不跑分析计算 |
| **容器计算面** | 算力节点上的 Linux 容器。R/Python 科学计算的执行面 |
| **数据面** | 算力节点数据盘上的 `/mnt/ssd/bio_data/` 存储根：`projects/<项目>/<线>/` 数据 + `bin/`、`envs/` 全局代码与环境 + `public_references/`、`system_logs/`（若未挂载，所有数据操作必须显式失败，不得静默落到其他分区） |
| **执行面指纹** | 记录"这一跑到底在哪跑"的 sha256 摘要（底座 `env_digest` + 计算面 `compute_digest`），用于溯源与 A/B 对照 |

## 台账

| 术语 | 定义 |
|---|---|
| **交接台账 (handoff)** | 跨会话状态快照：当前在哪、做了什么、下一步、遗留 |
| **踩坑台账** | 已踩过的坑：现象 → 根因 → 解决。动手排查前先搜 |
| **操作台账** | 每次操作的流水记录：做了什么 / 结果 / 产出 / 遗留 |
| **任务台账 JSON** | 工作流每步执行后落盘的结构化记录，供 Agent 读取做状态追踪与重试 |

## 数据契约

| 术语 | 定义 |
|---|---|
| **桥接格式** | 跨语言传递用的显式文件格式：单细胞 `.h5ad` / `.loom` / `.mtx`，表格 `TSV`（首列 `gene_id` 或 `gene_symbol`），不搞脆弱的跨语言内存桥接 |
| **桥接检查点** | 转换后必须校验：基因名、矩阵方向（基因×细胞 还是 细胞×基因）、细胞名、embedding 是否保留。校验不通过即停 |
| **外部验证冻结** | bulk 线的独立 GEO 验证集只做冻结评估：不重新筛基因、不重新调参。验证集内部可去批次，但禁止与训练集合并校正后再评估 |
